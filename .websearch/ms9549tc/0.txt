小编最近在寻找 AI 组件库时，发现了一个宝藏项目：Element Plus X。它基于 Vue 3 和 Element Plus，让 AI 开发变得超级简单。今天就来给大家安利一下！
这个 AI 组件库目前已在 Github 开源。
Element Plus X 是什么？
这是一个专门为 AI 场景，基于 Vue 3 和 Element Plus 的企业级 AI 组件库设计的组件库。它最大的特点是：开箱即用，零配置集成。对于想要快速实现 AI 功能的开发者来说，简直是福音！
核心优势
内置 AI 组件
聊天机器人：支持多种消息类型
语音交互：支持语音输入和播放
智能输入框：支持 AI 补全
使用超简单
基于 Element Plus 设计，风格统一
零配置就能用，省心省力
按需加载，性能杠杠的
安装方法
推荐使用 pnpm（速度最快）：
pnpm install vue-element-plus-x
一键获取完整项目代码 go
或者用 npm：
npm install vue-element-plus-x
一键获取完整项目代码 go
快速上手
按需引入（推荐）
<script>
import  { BubbleList, Sender } from  'vue-element-plus-x'
const  list = [
  {
    content:  '你好，Element Plus X' ,
    role:  'user' ,
  },
]
</script>
<template>
  <div style= "display: flex; flex-direction: column; height: 230px; justify-content: space-between;" >
    <BubbleList :list= "list"  />
    <Sender />
  </div>
</template>
一键获取完整项目代码 go
全局引入
// main.ts
import  { createApp } from  'vue'
import  ElementPlusX from  'vue-element-plus-x'
import  App from  './App.vue'
const  app = createApp(App)
app.use(ElementPlusX)
app.mount( '#app' )
