方法一：基础标签映射法（ customHtmlTags  +  setCustomComponents ）
这是最直接且推荐的入门方法，适用于简单的自定义标签场景。通过 customHtmlTags 白名单声明可信标签，再使用 setCustomComponents 注册对应组件，实现标签到组件的映射。
首先在Markdown渲染组件中声明自定义标签：

content = "<thinking>正在思考...</thinking>"
:customHtmlTags = "['thinking']"
/>

setCustomComponents ( 'docs' , {  thinking :  ThinkingNode  })

方法二：内置节点覆盖法
markstream-vue允许通过 setCustomComponents 覆盖内置节点的渲染方式，如代码块、图片、表格等。这对于定制化系统默认组件样式和行为非常有用。
例如，替换默认的代码块渲染器为基于Shiki的增强版：
import  {  MarkdownCodeBlockNode , setCustomComponents }  from 'markstream-vue'
setCustomComponents ( 'code' , {  code_block :  MarkdownCodeBlockNode  })

方法三：作用域组件注册法
为了避免全局组件冲突，markstream-vue支持通过 customId 参数注册作用域限定的自定义组件。这在多租户应用或复杂项目中尤为重要。
// 注册docs作用域的自定义组件
setCustomComponents ( 'docs' , {
thinking :  DocsThinkingNode ,
answer :  DocsAnswerBox
})
// 注册chat作用域的自定义组件
setCustomComponents ( 'chat' , {
thinking :  ChatThinkingNode ,
reply :  ChatReplyBox
})
